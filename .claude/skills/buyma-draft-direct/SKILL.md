# 商品URL → BUYMA出品画面に直接入力 → 下書き保存

ユーザーはオーストラリア在住のBUYMAバイヤー（ショップ: https://www.buyma.com/buyer/11546107.html）。
出品APIでは反映されないことがあるため、**BUYMAの出品画面をChromeで直接操作**して下書きを作る。
ユーザーは下書きを最終確認し、自分で「出品」を押す。

## 絶対ルール
- **「出品する」「公開」系のボタンは絶対に押さない。** 最後に押すのは「下書き保存」だけ。
- ユーザーが作業中のタブは触らない。新しいタブで作業する。
- ログインが切れている／CAPTCHAが出た場合は止めてユーザーに頼む（パスワードを入力しない）。
- 入力する全テキストから記号と絵文字を消す（BUYMAでエラーになる）:
  `s.replace(/[™®©℠℗]/g,'').replace(/\((TM|R|C)\)/gi,'').replace(/[\uD800-\uDBFF][\uDC00-\uDFFF]/g,'').replace(/[☀-➿]/g,'').replace(/\s+/g,' ').trim()`
  （商品コメントは改行を残すので、最後の `\s+` 置換は使わない）
- 複数URLを渡されたら1件ずつ順番に処理し、1件終わるごとに下書き保存してから次へ進む。

## 1. 商品情報を取る（買付先ページ）
新しいタブで商品URLを開く。
- **Shopifyのサイト**: そのページで `fetch(location.pathname + '.js').then(r=>r.json())` を実行する。title / vendor / tags（x-gender, type_）/ price（セント単位なので÷100）/ compare_at_price / options / variants（各サイズ・カラーの available）/ images を取る。
- **それ以外のサイト**: get_page_text でページを読み、商品名・ブランド・価格(AUD)・カラー・サイズ別の在庫・素材・説明・画像URLを取る。
- 取れなかった項目は推測で埋めず、最後の報告で「未入力」と伝える。

## 2. 入力する内容を作る
### 商品名
- 形式: `[ブランド名] 商品名`（ブランドなしの場合は商品名だけ）
- 半角換算で60文字以内（全角は2文字分）。超える場合は単語の途中で切らず、最後のスペースの位置で切る。

### 商品コメント
1. 商品説明を**自然な日本語**で書く（特徴・素材・サイズ感・おすすめポイント）。誇大表現や、根拠のない「限定」「完売必至」は使わない。
2. 読みやすくするため、「。！？」の後は空行を入れる。読点が30文字以上続いたら「、」の後で改行する。
3. その下に `ーーーーーーーーーーーーー` を入れ、続けて同じフォルダの `fixed-comment.txt` の全文をそのまま貼る。

### カラー
- カラー名は日本語（例: ブラック、オフホワイト）。全角13文字（半角26文字）以内。
- 色の系統は近いものを選ぶ: ホワイト／ブラック／グレー／ブラウン／ベージュ／グリーン／ブルー／パープル／イエロー／ピンク／レッド／オレンジ／シルバー／ゴールド／マルチカラー など。

### サイズ（半角13文字以内）
- 規格の表記は1つに絞る。優先順は **cm → EU → US(W/M) → UK → AU**。それ以外の規格は消す。
- S/M/L などの文字サイズがあれば `S(AU8)` のように併記する。13文字を超える場合は文字サイズだけにする。
- One Size／OS は `FREE` にする。

### 在庫
- available なサイズ×カラー＝「買付可（受注後買付）」、それ以外＝「在庫なし」。受注可能数の既定値は10。

### 価格（円）
- 為替レート: 毎回ユーザーに確認する。指定がなければ直近に使ったレートを使い、報告で必ず「このレートで計算しました」と伝える。
- 国内送料 10 AUD、国際送料(AUS→JPN) 35 AUD
- 希望利益 = 商品代金(AUD) × レート × 0.2
- **販売価格 = (商品代金 + 国内送料 + 国際送料)×レート + 希望利益 を (1 − 0.055) で割り、100円単位で切り上げる**
- 参考価格: compare_at_price があれば、それをレートで円に換算して入れる。

### 共通の設定
- 買付地: オーストラリア／発送地: オーストラリア
- 購入期限: 今日から90日後
- 配送方法: ユーザーが普段使っている方法（Australia Post）を選ぶ
- 関連リンク（色・サイズ補足欄）: `ショップ\nhttps://www.buyma.com/buyer/11546107.html`
- 非公開メモ（買付先メモ）:
  ```
  【買い付け先】<商品URL>
  【買い付け金額】<価格> AUD
  【レート】1AUD=<レート>円
  【国内送料(AUS)】10 AUD
  【国際送料(AUS→JP)】35 AUD
  【予想利益】¥<利益>（利益率<%>）
  ```
  利益 = 販売価格 − (代金+送料)×レート − 販売価格×0.055
- 買付先URL欄があれば、商品URLを入れる。

## 3. BUYMAの出品画面に入力
1. 新しいタブで BUYMA → マイページ → 「出品する」（新規出品）を開く。
2. read_page で画面の項目を確認しながら、上から順に入力する: 商品名 → 商品コメント → ブランド（検索して選ぶ）→ カテゴリ（大→中→小）→ カラー・サイズ・在庫 → 価格・参考価格 → 買付地・発送地 → 配送方法 → 購入期限 → 関連リンク → 買付先・メモ。
3. 選択肢やプルダウンは、クリックして候補から選ぶ。form_input で入らない欄は、click してから type する。
4. **画像**: 商品画像を最大5枚、BUYMAの画像アップロード欄に入れる。ページ内のJSで、画像を fetch → canvas で正方形に余白を足す（背景は白）→ File にする → `DataTransfer` で `input[type=file]` に入れて change イベントを発火する。CORSで取れない画像は、何枚目が入らなかったかを報告する。
5. 入力し終わったらスクリーンショットで全体を見直し、エラー表示（赤字）がないか確認する。エラーがあれば直す。
6. **「下書き保存」を押す。** 保存できたら、下書き一覧に表示されていることを確認する。

## 4. 初回の作業でやること（画面の手順を覚える）
BUYMAの出品画面の構成は変わることがある。初回、または画面が変わって入力がうまくいかなかった時は、うまく入力できた方法（欄の名前、クリックの順番、癖のある欄）をこのファイルの末尾「画面メモ」に追記するよう、ユーザーに提案する。

## 5. 報告（短く・1件ごと）
- ✅ 下書き保存しました: 商品名
- ブランド／カテゴリ／カラー／サイズと在庫／販売価格（代金・レート・予想利益と利益率）／画像の枚数
- ⚠️ 確認してほしい点: 推測で入れた項目（カテゴリ、サイズ規格、色の系統）、入らなかった項目
- 最後に「下書きを確認して、問題なければ出品ボタンを押してください」
